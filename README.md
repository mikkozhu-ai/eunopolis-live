# 经世济国 · 1.0 正式版

纯前端无内购的六边形宏观经济与国土经营策略游戏。在线游玩：https://mikkozhu-ai.github.io/eunopolis-play/

## 核心特性

- **217 块六边形山河疆域**：169 块核心本土 + 48 块远洋边疆，按地球自然比例分布地形，勘探 34 种现实矿产与 6 种终局奇异资源。
- **75 项现代与科幻产业链**：59 项现实行业 + 16 项未来架空产业，配备全景交互式产业链建筑树，贴邻上下游结成供需路网，统筹全国电力与供水生命线。
- **现代国家治理与三格奇观**：五大现代国体、30 张历史名臣政策卡、三轨专项预算、6 项五年规划、24 座市政设施与 8 座三格国家级奇观。
- **君主巡察、229 位传奇人物与文明传承**：主公乘飞艇巡察山河、督办工程、指点人才、互通贸易、颁布政令；双轨突破养成 229 位名臣企业家，达成三幕盛世纪元碑并开启二周目文明传承（NG+），角逐全球云端开荒天梯与沙盒展示榜。

## 游玩与存档说明

- 推荐使用桌面端 Chrome / Edge / Safari 体验完整 3D 全景视效（亦内置清爽 2D 战略沙盘与移动端触控适配）。
- 进度实时保存在当前浏览器本地（`eunopolis.v10`），支持 JSON 存档导入/导出与全球云端天梯快照备份恢复。
