# 经世济国 · v1.1 正式版

纯前端、零内购的六边形宏观经济与国土经营策略模拟游戏。在线游玩：https://mikkozhu-ai.github.io/eunopolis-live/

## 核心特性

- **217 块六边形山河疆域**：169 块核心本土与 48 块远洋边疆，按自然地理比例分布地形，支持勘探与贸易置换 34 种现实矿产与 6 种终局奇异资源。
- **75 项现代与未来产业链**：59 项现实行业与 16 项架空终局产业，内置全景交互式产业链建筑树；贴邻上下游结成供需路网，统筹全国电力、供水与市政承载生命线。
- **制度化施政与三格国家奇观**：5 类基本体制、30 项体制政策、6 项满 20 季度周期的五年规划、三轨专项预算、经济特区、24 座市政设施与 8 座跨三格三角形基座的国家级地标奇观。
- **执政调研、229 位人物养成与真人天梯**：主公按实时季度时钟开展实地调研、督办工程、指点人才、资源贸易与颁布政令；支持同名卡与星钻猎头双轨突破养成 229 位历史学者与商业人物，参与纯真人全球云端 GDP 总榜与 75 产业龙头竞逐。

## 游玩与存档说明

- 推荐使用桌面端 Chrome / Edge / Safari 体验完整 3D 微缩沙盘视效（内置 2D 战略沙盘切换与移动端触控适配）。
- 进度实时保存在当前浏览器本地（`eunopolis.v11`），支持 JSON 存档导入导出，以及基于「公开展示编号 + 专属迁移密钥（`EK-...`）」分离机制的跨设备云存档同步。
