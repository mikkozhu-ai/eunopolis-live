# 经世济国 · v2 体验与数值增强版

基于《经世济国》0.9 内测版深度优化的独立单页版，保留 100% 本地存档兼容（`eunopolis.v04`）。

## 主要优化内容

### 1. 大地图相机与视野跟随
- **视野安全区智能跟随（3D / 2D 同步）**：动态感知顶部简报、侧栏、左下 HUD 与地块详情卡边界；点击视野安全区内的地块镜头零乱跳，贴边或被面板遮挡时仅做最小幅度轻推，通过 UI 跳转边疆时自动锚定故土重心防止中心空屏。
- **光标锚定缩放与键盘操控**：支持滚轮朝鼠标光标缩放，`WASD` / 方向键平滑移图，`Q` / `E` 旋转视角，`Space` 定位主公，`Esc` 逐层关闭面板。

### 2. 主公辨识度与交互打磨
- **主公高可见度重塑**：亮色象牙白镶金飞艇涂装、常驻最上层「♛ 主公」悬浮铭牌、飞艇本体直接点击选中、视野外屏幕边缘动态罗盘指示器及右侧工具栏皇冠定位键。
- **UI 细节修复**：`?` 说明弹窗防底层穿透遮罩、中窄屏面板与底部详情卡零重叠避让、远端迷雾地块一键定位最近可开拓边疆、每日签到并入任务栏角标与「全部领取」。

### 3. 核心数值与中后期节奏调优
- **体力与政令节奏**：施政体力消耗 `2 -> 1`（每日上限 `3 -> 5`），每年春季额外回复 `1` 点体力；大图调研骰子机动性补正，过路奖励随首都与全国 GDP 成长。
- **人才双轨突破与对口上限**：行业匹配人物驻守可使地块等级上限 `+1`（最高 Lv.6）；满级关口支持「同名卡」或「星钻猎头」双轨突破。
- **产业链协同与国家科研预算**：上下游供需边加成随两端设施等级提升；新增四档「国家科研预算」将富余税收转化为全国产值与人才历练增速，并配合 Lv.4–6 阶梯维护费平衡后期经济。

## 本地运行

项目为纯静态单页应用（含 `bgm/` 背景音乐目录），在仓库根目录启动任意静态服务器即可畅玩：

```bash
python -m http.server 8765
# 然后在 Chrome / Edge 打开 http://127.0.0.1:8765/
```
